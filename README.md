# ATM

A desktop ATM application developed with Java and JavaFX

## Features

-User login authentication
-Withdraw money
-Deposit money
-Transfer money
-Transaction history
-Change PIN
-Account information

## Technologies

-Java
-JavaFX
-Object-Oriented Programming (OOP)
-File handling
